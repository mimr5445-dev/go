# سجل القرارات

## D-001 — الذاكرة في المستودع (2026-11-09، معتمد بالتكليف)
GitHub والكود وMarkdown بمعرفات ثابتة هي المرجع، لا ذاكرة المحادثات. البديل المستبعد: الاعتماد على تقارير دردشة غير متاحة للنموذج التالي. القبول يتطلب أدلة لا تصريح النموذج فقط.

## D-002 — حفظ البنية والعمل التاريخي (2026-11-09، معتمد بالتكليف)
نبقي src الحالي وملف plugin والصور والفروع كما هي، ونضيف طبقة توجيه/إدارة. استُبعد نقل الكود أو cherry-pick تحسينات الهاتف لأنه خارج التأسيس ويحتاج تحققاً. الأثر: GO-UI-001 يبقى منفصلاً.

## D-003 — لا main أو Production دون موافقة (2026-11-09، معتمد بالتكليف)
كل العمل على arena/5c5b59d2-go؛ المراجعة لا تعني تفويض دمج أو نشر. استُبعد الدمج التلقائي ولو نجحت الاختبارات.

## D-004 — REVIEW عند غياب القبول المستقل (2026-11-09، إجراء لهذا التسليم)
تبقى GO-FOUNDATION-001 في REVIEW بعد التنفيذ والأدلة، إلى أن يراجعها المستخدم/مراجع موثق؛ لا نضعها في completed بمجرد إعلاننا. المحاكاة من الملفات ممكنة، لكن لا نزعم تشغيل نموذج مستقل إن لم تتوفر آليته.

## D-005 — تثبيت محافظ للتقييم (2026-11-09، قرار تشغيل لا سياسة دائمة)
استُخدم Bun 1.4.4 frozen بعد فشل npm. استُبعد force/legacy-peer-deps وتعديل package.json لتجنب إخفاء تعارض خارج النطاق. توحيد مدير الحزم نهائياً مقترح GO-TOOL-001 وليس قرار منتج معتمداً.
